# Handoff, 2026-11-17: where 0.11.0 stands

Work moves to a new set of servers. This file says what is on main, what waits on branches, and what comes next, so a
new session can start from a checkout. The plans and task files of the tracks (R7, S2, the R3 leftovers), the agents'
notes and the session's memory are in a tarball outside the repository (they name local paths); copy it over with
the checkout and unpack it into the state directory of the subagent-economy skill.
